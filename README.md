# 🔐 Identity Lifecycle Management (JML) Lab – IAM Hands-On Project

As part of continuing to build my Identity & Access Management (IAM) and governance skills, I completed a hands-on **Identity Lifecycle Management (Joiner, Mover, Leaver)** lab using Microsoft Entra ID.

This project simulates how organizations securely manage employee identities and access throughout their time at a company.

## 🎯 Project Objective

To demonstrate how IAM teams manage **user provisioning, access control, and secure offboarding** using role-based access principles.

## 🧑‍💻 What I Practiced

🔹 **User Provisioning (Joiner)**
Created new user identities and assigned appropriate access based on job role and department.

🔹 **Role-Based Access Control (RBAC)**
Built security groups and assigned users to groups to simulate least-privilege access management.

🔹 **Role Change Management (Mover)**
Updated access permissions when an employee’s role changed, ensuring permissions aligned with their new responsibilities.

🔹 **Secure Offboarding (Leaver)**
Disabled user accounts and removed access to prevent unauthorized authentication after termination.

🔹 **Access Governance Review**
Conducted a manual access review to confirm permissions matched employee job functions.
